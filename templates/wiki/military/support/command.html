Command & Control

Command and Control (C2) represents the ability of military headquarters to coordinate and direct friendly forces. Maintaining an effective command structure allows combat units to operate at full effectiveness across the battlefield.

Headquarters

Headquarters (HQ) units serve as the nerve centre of military operations, providing leadership, coordination, and command to friendly forces.

An HQ can command friendly combat units within its command range, provided the unit is within the HQ's size limit.

Command Range

A Headquarters commands friendly combat units within a 2-sector radius.

A unit is considered in command when it is within this radius and its size is equal to or smaller than the HQ's size.

There is no limit to the number of units an HQ can command, provided those units meet the range and size requirements.

HQ Size

The size of an HQ determines the maximum size of combat unit it can command.

An HQ can command units that are the same size or smaller than itself.

Example A Size 3 HQ can command Size 1, Size 2, and Size 3 combat units within 2 sectors.

A Size 4 combat unit therefore requires a Size 4 HQ within command range to remain in command.

Out of Command

If a combat unit is not within the command range of a suitable Headquarters, it becomes Disorganised.

This can occur when a unit moves beyond the range of its HQ or when the available HQ is too small to command the unit.

Disorganisation

Disorganisation reduces a unit's ability to conduct military operations effectively.

A Disorganised combat unit suffers the following penalties:

  • Can only move 1 sector per turn.
  • Deals half damage, with fractions rounded down.
  • Has half defence, with fractions rounded down.

These penalties remain relevant until the unit is once again within the command range of a suitable Headquarters.

Command and Military Operations

Maintaining command coverage is particularly important when conducting offensive operations. As forces advance across the battlefield, HQ units may need to move forward or be positioned appropriately to maintain command over advancing formations.

Large formations also require appropriately sized Headquarters. A force may therefore need to maintain multiple HQ units or carefully coordinate its formation sizes when operating across a wide front.

Command and Combat

Command status directly affects combat effectiveness. A unit that becomes Disorganised suffers reduced damage and defence, making it significantly less effective in combat.

Command is therefore an important consideration when positioning forces before an engagement. Maintaining HQ coverage can be just as important as maintaining the combat strength of the frontline units themselves.
